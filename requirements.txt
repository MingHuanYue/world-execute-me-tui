# Why imageio-ffmpeg is required:
#   All encoding goes through imageio_ffmpeg.get_ffmpeg_exe(). The ffmpeg on
#   your PATH frequently lacks libx264, which would silently produce broken
#   output. imageio-ffmpeg ships its own ffmpeg 7.1 with libx264 / aac /
#   h264_nvenc.
#
# If pip cannot write to your user site-packages, install to a folder instead:
#   pip install --target <somewhere>/_vendor imageio-ffmpeg==0.6.0
#   (config.py auto-adds a _vendor/ folder sitting next to the repo)
#   Or point the DSH_FFMPEG environment variable at any ffmpeg with libx264.
