## 1. 算法与参数

| 阶段 | 做法 | 参数 |
|---|---|---|
| 解码 | ffmpeg `-vn -ac 1 -ar 44100 -c:a pcm_s16le` | ffmpeg 全路径见任务环境说明 |
| STFT | Hann 窗，幅度谱 | n_fft 2048，hop 512（86.1328 帧/s） |
| 能量包络 | 滑窗 RMS + 峰值包络 | 20 ms 窗 / 20 ms 步长 → 10595 点，带时间戳 |
| onset | **spectral flux**：`log1p(20·|X|)` 相邻帧正差分求和 → 去均值除标准差 | 峰值拾取：±0.12 s 滑动均值 + δ=0.30 阈值，最小间隔 45 ms → 1748 个 |
| BPM | onset 强度曲线自相关 → **comb 打分**（lag, 2·lag, 3·lag, 4·lag 加权 1 / 0.55 / 0.35 / 0.22，各 ±2% 取峰）→ 抛物线细化 | 搜索 60–180 BPM |
| 拍点 | 对给定 BPM 穷举相位（P/400 步），最大化拍点处 flux 之和 | 输出 462 个拍点 + 强度 |
| 段落特征 | **1 Hz**：40 维 log-mel（30–8000 Hz）+ 谱质心 + log-RMS | 列 z-score 后归一化 |
| 自相似 | 余弦自相似矩阵 + **Gaussian 棋盘核** novelty | 粗尺度 k=16（±16 s）、细尺度 k=8 |
| 边界打分 | 0.72 s 平滑后的 **±6 s 电平台阶(dB)** ×1.0 + **带内能量比台阶** ×0.6 + **谱质心台阶** ×0.4 + **粗尺度 novelty（未归一化，防噪声放大）** ×0.5 | 各分量在“±6 s 全为有声段”的样本上做 99.5 分位稳健归一化 |
| 峰值拾取 | 局部极大 + 最小段长 8 s + 阈值 0.42×max | 4k 得 8 个数据边界 |
| 边界精修 | 在 ±1.2 s 内找 log-RMS 最大跳变点 | 亚秒精度 |

**为什么不用纯 novelty 归一化曲线定阈值**：早期版本把 novelty 归一化到 max=1 后，安静段（165–195 s）的微小起伏被放大成 1.0 的“假峰”，导致出现每 7 秒一个边界的碎段。改成未归一化 + 稳健归一化后消失。

**静音掩码**：只有 ±6 s 窗口全为有声（> −45 dBFS）的点才参与边界打分，否则“音乐↔静音”边缘会产生 80 dB 的台阶，把归一化尺标顶爆（实测 cmd 版阈值一度被抬到 0.719，只剩 2 个边界）。

## 2. BPM 与拍点

### 2.1 候选与置信度

| # | BPM | comb 分 | 30 s 窗一致率 | 判断 |
|---|---|---|---|---|
| 1 | **130.83** | 0.910 | 0.92（13 窗） | **采纳** |
| 2 | 65.83 | 0.846 | 0.92（13 窗） | 同族半速别名 |
| 3 | 86.86 | 0.628 | **0.08** | 排除（跨窗几乎不一致，130.83×2/3 的多重比伪影） |

### 2.2 独立佐证（不是同一算法的重复输出）

- **拍点命中率 0.723**：462 个拍点中有 72.3% 落在检测到的 onset 的 ±50 ms 内（cmd 版 0.688，同量级）。
- **强 onset 间隔众数 = 0.23 s**：取强度前 30% 的 524 个 onset，间隔直方图峰值 0.23 s ≈ 130.83 BPM 的八分音符（0.2293 s）；次峰 0.47 s ≈ 整拍（0.4586 s）。若真实拍速是半速 65.4 BPM，这些事件就要解释成十六分音符，与谱面密度不符。
- 段落边界落在约 1.83 s（小节）的倍数附近，且 15 段结构与固定字幕轨时间戳逐段吻合（§3）。

### 2.3 诚实的保留

自相关对节奏只能定到**“脉冲”级别**，130.83 与 65.83 是同一个脉冲的两种记法，两者的跨窗一致率都是 0.92。选 130.83 是**约定**（把拍定义为感知上的四分音符）而非数据强制。若下游要半速记谱，拍长取 0.9172 s、小节 3.669 s，所有 onset / 段落数据不用改。

首拍 `first_beat = 0.186 s`，相位在 14.02 帧处，每拍 0.4586 s。

## 3. 段落切分

### 3.1 两路证据

1. **数据边界（本管线自动检出）**：4k 版 8 个 —— 14.81 / 31.09 / 58.87 / 76.11 / 102.91 / 161.91 / 194.13（+201.85 判为伪边界，见 §3.5），分数 0.61–1.35。
2. **结构锚点（弱先验）**：来自主参考片固定字幕轨的 15 个时间戳，只取**时间戳 + 结构标签**，不含任何歌词文本。

### 3.2 合并规则

- 锚点与数据边界在 ±6 s 内**按距离从小到大全局配对**（不是按锚点顺序贪心，否则 70 s 的 bridge 会抢走 76.11 s 那个更匹配 verse2 的边界）。
- 配对成功 → 边界时间取**数据精修值**，`evidence = "both"`。
- 未配对但 ±5 s 内数据分数 ≥0.35（且该点未被别的锚点占用）→ `evidence = "novelty"`。
- 未配对且数据几乎无响应 → `evidence = "lyrics_anchor"`。
- 剩余强数据边界（分数 ≥0.55）且位于最后一个锚点之前 → `evidence = "novelty"`（本次为空）。

置信度：`both` 且 \|Δ\|≤1 s → 0.90；≤2.5 s → 0.80；≤6 s → 0.70；`lyrics_anchor` → 0.55；`novelty` → 0.50。文件起点固定为 1.00。

### 3.4 哪些边界可信、哪些是弱判断

**高置信（数据 + 锚点双证，Δ≤2.1 s）**
- 14.81 s（intro→全奏，电平 +3.3 dB、带内能量比 0.40→0.49）
- 31.09 s、58.87 s（Δ=−0.13）、102.91 s、161.91 s、194.13 s（Δ=+1.13）
- 最硬的是 **58.87 s** 与 **161.91 s**（Δ 分别 −0.13 / +1.91，且 data_score 0.72 / 0.79）

**中置信（锚点有、数据仅在 ±5 s 内给出弱响应）**：46.00、70.00、85.00、95.00、111.00 s。

**弱判断（只有锚点，数据完全无响应）**：118.00 s（chorus4 起点）与 142.00 s（instrumental_execution 起点）——这两处 ±5 s 内数据分数只有 0.32 / 0.30，且 118 s 的锚点与最近数据边界（102.91 s）相距 15 s。**如果要给渲染层做“哪些边界可以微调”的白名单，就是这两条。**

### 3.5 已剔除的伪边界

- **201.85 s**（data_score 1.281，本可触发）：位于最后一个结构锚点之后，且其 ±6 s 台阶窗口跨过 207 s 的“音乐→衰减”沿，属于电平台阶被结尾拉出来的假峰。已按“边界必须早于最后一个锚点”规则剔除。
- 早期版本的 183 s / 192 s 之争：4k 在 183 s 有一个归一化 novelty=1.0 的孤立峰，但 cmd 版在对应位置（187.96 s）**完全没有响应**，而 192 s 的能量/音色台阶在两版都成立（cmd 197 s，Δ=5.0 s ≈ 整体偏移）。因此 183 s 判为编码差异造成的假边界，真边界是 192 s（本题合并后落到 194.13 s，因为取的是数据精修 + 锚点 193 s 的组合）。

## 5. 两版是否同一录音：**是**

| 证据 | 数值 |
|---|---|
| 原始波形互相关峰值 | **0.9764**（lag = −4.9563 s，4 倍抽取后 FFT 全互相关） |
| 10 个独立 15 s 窗口的局部偏移 | **全部 −4.9563 s**，corr 0.848–0.908，**漂移 0.0000 s** |
| 音乐内容长度 | 4k **206.948 s**，cmd **206.948 s**（逐毫秒相同） |
| 时长差 12.564 s 的构成 | 头部多 4.956 s + 尾部多 7.606 s（0.002 s 为舍入） |
| 逐秒对齐 | 按 +4.956 s 对齐后，两版 **band_ratio 逐秒吻合到小数点后三位**（如 0.401/0.405、0.513/0.515），dB 只差恒定 **+1.24 dB**（cmd 更响，属不同响度归一化/编码，不是不同录音） |
| 静音位置 | cmd 片头 5.00 s 数字静音（−106.7 dB）在 4k 中不存在，正好等于整体偏移 |
| 段落对齐 | 15 段起点按 +4.956 s 平移后，**14 段 Δ=0.000 s，最大偏差 0.976 s**（1 Hz 特征分辨率内） |

结论：**同一母版录音，cmd 版 = 4k 版整体后移 4.956 s、电平高 1.24 dB、尾部多 7.6 s 静音**。两版段落**完全对齐**（同一条时间轴平移即可复用）。

## 7. 局限

1. 段落特征分辨率是 **1 Hz**，边界精修后仍有约 ±0.5 s 的不确定度（交叉验证的最大偏差 0.976 s 即来自此）。
2. 音色/能量台阶类边界（14.81、194.13 s）对混音版的电平变化敏感，换一个母版可能平移 1–2 s。
3. 半速/全速记谱是约定，不是数据结论（§2.3）。
4. `vocal` 启发式区分度弱，只有结构性器乐段（build / instrumental_execution）可当结论。
5. 15 段的结构标签来自固定字幕轨时间戳（弱先验）。其中 **118 / 142 s 两条边界数据无支持**，是本次最弱的两条。

## 8. 版权

本分析只输出**时间戳、能量/频谱统计量、结构标签**。没有从参考资料中提取、转录或存储任何受版权保护的画面、音频、歌词文本或素材；`sections.json` 的 `name` 全部是 intro / verse / chorus 这类结构术语。
